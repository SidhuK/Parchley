# Support and known limits

Parchley requires macOS 26 or later and currently targets Apple Silicon. OCR requires the separately installed PP-OCRv6 Small model. It is intended for printed text. Handwriting, cloud recognition, and guaranteed recovery of complex layouts are outside the first release.

When a conversion fails, retry the document or import a fresh copy. Include the engine/runtime versions and the visible error when reporting a reproducible parser failure. Do not include the source PDF unless you have permission to share it.
